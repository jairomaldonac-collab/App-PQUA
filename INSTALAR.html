⚠ IMPORTANTE — Abrir siempre desde HTTPS, no desde archivo local.
Si abre index.html directamente desde el celular (content://...), las búsquedas automáticas en EFSA, ICA, PLM y demás fuentes NO funcionarán por restricciones de seguridad del navegador.

Solución: Hospede la app en GitHub Pages (gratis, permanente) o Netlify. Instrucciones abajo. ⬇

⭐ Opción 1 — GitHub Pages RECOMENDADO · GRATIS · HTTPS

Una vez configurado, accede desde cualquier dispositivo con una URL fija tipo https://TU-USUARIO.github.io/dossier-pqua/

1
Cree una cuenta gratis en github.com si no tiene una
2
Cree un repositorio nuevo llamado dossier-pqua (público)
3
Suba los archivos: index.html, sw.js, manifest.json y la carpeta icons/
4
Vaya a Settings → Pages → Source: Deploy from branch → main → / (root) → Save
5
En 2 minutos su URL estará lista:
https://TU-USUARIO.github.io/dossier-pqua/
6
Abra esa URL en Chrome (Android/PC) o Safari (iPhone) → toque "Instalar" o "Agregar a pantalla de inicio"
✅ Desde HTTPS todas las búsquedas automáticas (ICA, PLM, EFSA, EPA, etc.) funcionan perfectamente. La app queda instalada como PWA en su dispositivo.

🚀 Opción 2 — Netlify Drop MÁS FÁCIL · GRATIS

1
Vaya a app.netlify.com/drop en su computador
2
Arrastre la carpeta pwa-dossier/ completa al área de drop
3
En 30 segundos obtiene una URL tipo:
https://random-name-12345.netlify.app/
4
Abra esa URL en su celular → instale como PWA
💡 Puede personalizar el nombre del sitio en la configuración de Netlify. También puede re-deployar cuando haya actualizaciones.

📡 Opción 3 — Servidor local (sin internet externo) AVANZADO

Si tiene Python instalado en su PC, puede servir la app localmente y acceder desde el celular por WiFi.

1
En la carpeta pwa-dossier/ abra una terminal y ejecute:
python -m http.server 8080
2
Averigüe la IP local de su PC (ej: 192.168.1.100)
3
En el celular (misma red WiFi) abra:
http://192.168.1.100:8080
⚠ Con HTTP local (no HTTPS) algunas llamadas a la API pueden seguir bloqueadas dependiendo del navegador. GitHub Pages o Netlify son más confiables.
✅ Resumen: La opción más simple y permanente es Netlify Drop (2 minutos, arrastrar y soltar). GitHub Pages es ideal si ya usa GitHub. En ambos casos la app queda accesible desde cualquier dispositivo con una URL HTTPS fija.
